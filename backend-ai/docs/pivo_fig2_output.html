C · PWA Supply Simulator Math (React)
Exact Prep (Y = Demand)
Profit = (Price - Cost) × Y
No waste, no stockout risk. Maximum efficiency.
Underprep (Y < Demand)
Profit = (Price - Cost) × Y Loss = (Demand - Y) × (Price - Cost)
Sold out — Opportunity loss is displayed dynamically.
Overprep (Y > Demand)
Profit = (Price - Cost) × Demand Waste = (Y - Demand) × Cost
Waste cost is quantified financially in IDR.
Owner drags a slider to set 'Y'. Client natively recalculates all arithmetic from the JSON payload. No API call needed.
